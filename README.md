# Forge CRM

Merchant-funding sales desk.

**Pages URL:** https://robbyrob10.github.io/Grokcrm/

**Repo:** https://github.com/robbyrob10/Grokcrm

## Turn on Pages

1. Repo **Settings → Pages**
2. Source: **GitHub Actions** (workflow already in `.github/workflows/pages.yml`)
3. Upload the desk file: **Add file → Upload files** → drop `index.html` (the Forge CRM HTML) over the current loader, commit to `main`.
